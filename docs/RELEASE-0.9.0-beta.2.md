# NeriPlayer Win v0.9.0-beta.2

本地歌单管理补全 + 拖拽链路修复。beta 第二轮迭代,主线是让 beta.1 里
名义上线、实际不可用或有缺陷的拖拽交互真正可用,并把本地歌单从「能收藏」
推进到「能管理」。

## 新增

### 本地歌单管理

- 侧栏歌单右键菜单:重命名、删除(二次确认)、上移/下移
- 浏览本地歌单时,表格内整行拖拽调整曲目顺序,右键「从歌单移除」;
  远端歌单(网易云/B站/酷狗)不开放这两项,顺序由各平台自己决定
- 重命名与删除会同步清理排序键、最近列表、封面缓存里的引用,
  歌单 id 复用时不会串到新歌单

### 侧栏分区换序(本版起可用)

beta.1 的分区拖动实际无法发起:分区头未开放选中,Qt 的拖拽从不触发,
「⋮」把手只是个视觉提示。本版修复,并把把手从分区头右侧移到左侧,
不再与本地歌单的「+」按钮重叠。落点改按目标行的上半/下半判定,
向上拖一格不再是无反应的空操作。

## 修复

**侧栏拖放后条目消失。** 拖动换序松手后,被拖的条目会从侧栏消失:
拖分区头时整个分区连同子项一起消失,拖歌单时该歌单消失,重启后才回来。
根因在 Qt 的拖放收尾:以 MoveAction 结束的拖放,Qt 默认会删除源行;
自绘 dropEvent 不调基类时拦不住这一步。同类问题存在于本地歌单表格的
拖拽调序(拖完少一行)和分区内歌单排序(自 v0.2.0 上线起即潜在),
本版一并修复。

**两首酷狗歌同时命中播放行高亮。** 酷狗歌曲的内部 id 恒为 0,播放行
高亮按来源加 id 匹配,同表两首酷狗歌会一起命中,排序后表现为高亮
跳错行。匹配键已并入真实标识,与本地歌单去重键同源。

**侧栏当前子项左侧的异色竖条。** 选中或设为当前的子项,缩进区会出现
一条底层样式填的强调色竖条(浅色主题下尤其明显)。主题现把整条分支区
盖回面板色,亮暗两套主题与播放动态取色下均生效。

## 已知限制

以下为酷狗音源的既有行为,与 beta.1 相同:

- 酷狗音质目前只有 128k,更高档位服务端不放行,状态栏按实际码率显示
- 部分酷狗曲目已下架或仅客户端可播,点播提示无可用地址后自动跳下一首
- 歌单读取依赖扫码登录,播放依赖网页登录,两步都完成才有完整体验

## 安装与升级

1. 解压 `neriplayer-win-0.9.0-beta.2.zip`
2. 双击 `NeriPlayerWin.exe`

从 beta.1 升级直接解压覆盖。登录态、设置、本地歌单都在
`%APPDATA%\neriplayer-win\`,与程序目录分离;`local_playlists.json`
格式无变化。

## 性能

本版无性能目标改动。开发机实测(打包版,5 次取中位):

| 指标 | 实测 | 验收线 |
|---|---|---|
| 冷启动 | 749 ms | ≤1500 ms |
| 常驻内存 | 146 MB | ≤200 MB |
