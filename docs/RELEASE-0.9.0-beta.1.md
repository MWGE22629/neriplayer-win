# NeriPlayer Win v0.9.0-beta.1

第三个音源「酷狗音乐」接入 + 应用内自建本地歌单 + 侧栏分区可拖动换序。

这是 beta 版，主要目的是收集真实使用反馈。三源登录态与播放链路已在开发机实测打通，但覆盖面有限，遇到问题请带上日志（`%APPDATA%\neriplayer-win\logs\`）反馈。

## 新增

### 酷狗音乐（第三音源）

侧栏新增「酷狗 · 歌单」分区，与网易云、B站并列。支持登录、歌单读取、点歌播放，混入统一队列与三源搜索。

登录分两步，各管一半功能：

1. **扫码登录**：手机酷狗 App 扫一次码，拿到歌单读取权限。这个 token 有效期 30 天，程序每次启动会静默续期，只要不连续 30 天不开机就不用重扫。
2. **网页登录**：弹窗里登录一次酷狗账号。酷狗播放地址的鉴权载体是网页登录下发的 `KuGoo` 串，它与扫码 token 互不通用，无法由 token 推导，所以播放必须单独登录这一次。

已有网页凭据时第二次以后不会重复要求登录。

### 本地歌单

侧栏新增「本地歌单」分区，可跨音源收藏网易云 / B站 / 酷狗的歌。

- 分区头右侧「+」新建歌单
- 歌曲右键「添加到…」，可加入已有歌单或当场新建
- 歌单封面自动取第一首歌的封面，启动后异步预取
- 点击歌单可手动指定封面，手动值优先且不会被自动封面覆盖

本地歌单存在 `%APPDATA%\neriplayer-win\local_playlists.json`，纯本地数据，不涉及云端。

### 侧栏分区拖动换序

每个分区头右侧有竖排「⋮」把手，按住分区头任意位置拖动即可调整大类顺序。

- 「搜索」固定置顶、「设置」固定置底，不参与排序
- 顺序存在 `settings.json` 的 `section_order`，重启后保持
- 新增分区（如以后的第四个音源）自动追加到尾部，不会打乱已有顺序

## 已知限制

**酷狗音质目前只有 128k。** 搜索接口会返回 128k / 320k / 无损三档的标识，但服务端对播放接口统一只放 128k，请求更高档位时返回的 `privilege` 会掉到 0 并降级。这是服务端行为，客户端无法绕过。状态栏按实际拿到的码率显示，不会谎报无损。

**部分酷狗歌曲无法播放。** 歌单里可能包含已下架或仅客户端可播的曲目，点播时会提示「该歌曲没有可播放地址」，此时会自动跳下一首。实测「我喜欢」里这类曲目约占三成。

**酷狗歌单读取依赖扫码 token。** 只做网页登录能播放但不能读歌单；只扫码能读歌单但不能播放。两步都做完才完整。

## 安装

1. 解压 `neriplayer-win-0.9.0-beta.1.zip`
2. 双击 `NeriPlayerWin.exe`

单目录分发，不需要安装 Python 或 mpv。首次启动若 Windows SmartScreen 拦截，点「更多信息」→「仍要运行」（未做代码签名）。

## 从 0.8.x 升级

直接解压覆盖即可。登录态、设置、本地歌单都存在 `%APPDATA%\neriplayer-win\`，与程序目录分离，不会因覆盖丢失。

新增的 `kugou.json` 只在首次登录酷狗后生成，旧版本不会读它。
